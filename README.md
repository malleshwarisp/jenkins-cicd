# 🚀 Jenkins Pipelines – Real-World CI/CD Examples

This repository contains a collection of Jenkins pipelines (`Jenkinsfile`) designed for learning and demonstrating real-world DevOps practices using Jenkins.

### 🔧 What's Included
- Jenkins Declarative Pipelines
- CI/CD for Python, Node.js, and containerized apps
- Docker build & push pipelines
- SonarQube integration for code quality
- Kubernetes & Helm-based deployments
- Shared Libraries for reusable pipeline logic
